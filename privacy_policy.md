# Privacy Policy

**Effective Date:** March 28, 2026

## 1. Introduction

This Privacy Policy describes how the **Forex Market Analysis API & Chatbot** (“the Service”) handles information when users interact with the chatbot or access the API endpoints.

The Service provides analytics related to Forex markets, including trend detection, RSI (Relative Strength Index), EMA (Exponential Moving Average), and Fibonacci-based signals using external market data sources.

The Service is designed to operate with **minimal data collection** and prioritizes user privacy.

---

## 2. Information We Collect

### 2.1 Information Provided by Users

The Service accepts limited input parameters required for analysis. These may include:

* Forex symbols (e.g., EURUSD, GBPUSD)
* Timeframes (e.g., 5m, 15m, 1h, 1d)
* Indicator parameters (e.g., RSI period, EMA period)

These inputs are used **only for processing requests** and are not stored permanently.

---

### 2.2 Automatically Collected Information

When interacting with the Service, certain technical data may be automatically collected by the hosting infrastructure or API providers, including:

* IP address
* Request timestamps
* HTTP headers
* Usage logs
* Error logs

This information is used strictly for **system monitoring, debugging, and security purposes**.

---

## 3. How We Use Information

The information received is used solely for:

* Processing user requests and generating Forex analysis
* Calculating indicators such as RSI, EMA, and trend signals
* Monitoring system performance and uptime
* Detecting abuse, misuse, or security threats

The Service does **not use data for advertising, tracking, or profiling users**.

---

## 4. Data Storage and Retention

The Service does **not intentionally store user inputs or personal data**.

* Requests are processed in real-time
* No persistent database is used for user data
* Temporary logs may be retained by hosting providers for operational purposes

Retention duration depends on the policies of the underlying infrastructure providers.

---

## 5. Third-Party Services

The Service relies on third-party providers for functionality, including:

* Market data providers (e.g., yfinance)
* Cloud hosting and infrastructure services
* API and application frameworks (e.g., FastAPI)

These third parties may process limited technical data required to operate the Service under their own privacy policies.

---

## 6. Data Security

Reasonable technical and operational measures are implemented to protect the Service.

However:

* No system is completely secure
* Internet-based transmissions carry inherent risks

Users should **avoid submitting sensitive personal or financial information** to the Service.

## 7. Children's Privacy

The Service is **not intended for individuals under the age of 18** and does not knowingly collect personal data from children.

Users are solely responsible for their trading and investment decisions.
